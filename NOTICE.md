# Third-party data

Location data comes from GeoNames (https://www.geonames.org/), licensed under
Creative Commons Attribution 4.0 (https://creativecommons.org/licenses/by/4.0/).
Any product or API exposing this data must credit GeoNames and link to the license.

This codebase is an independent implementation written from the public GeoNames
file formats. It contains no code from the open-meteo/geocoding-api project.
